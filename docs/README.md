- 两份截图整理稿于 2026-09-20 整理，采用规范化排版，不是飞书原文的完整导出或逐字认证副本。
- 实战演练截图编号为 A01—A11，采购手册截图编号为 B01—B04，均按对应用户消息中的图片顺序编号。
- 两组截图图像目前仅作为对话附件提供，未在本地找到对应图像文件；本次落盘的是文本整理稿，不是原始截图归档。
- 整理稿中的“整理说明”“待确认”属于来源边界或差异说明，不属于公司新增规定。
- 表格中的工具价格、额度、支付与退款描述均保留截图当时的表述，不代表已核实的当前产品规则。
- 框架截图整理稿用于查阅截图可见要求，会议纪要用于补充背景。存在冲突时保留双方表述，由导师或组织方确认；不得自行合并或推定生效口径。
- 本目录是任务资料目录，不等同于最终交付包中的 `docs/`。最终交付目录要求见框架整理稿第 4.1 节。

## 优先确认事项

1. 评分采用十分制还是百分制，如何折算及判定通过。
2. 延期适用情形、扣分尺度及与会议纪要的冲突。
3. 部门实际采购、选题、中期、交付、答辩和报销截止日期。
4. Skill 是否为所有课题的必交内容，以及初版允许的 AI 辅助范围。
5. 选题申报表中尚未展开的范围及验收标准、正式评分表字段和部门附加规则。
6. 历史订单、活动期间续费、既有账户新增充值及分次采购的报销范围。
