## 3. 上机日检查清单（提前冻结）

1. 环境确认：adb devices 可见、root、目标树版本记录（git rev-parse HEAD）。
2. 采集：`mcp_service -c -t --svcmap`、`--list`、各服务 `--mcp`（tools/list 全量留档）。
3. L1 批次：推送本工具生成的配置，执行 5＋2 用例，抓 stdout＋logcat。
4. L2 批次：DeepSeek、Kimi 各跑选定任务，逐轮留痕。
5. 状态恢复：被修改的车况（如空调温度）恢复原值；服务重启确认。
6. 证据回采：pull 全部产物到 `tests/results/<run-id>/`，当天核对完整性。
