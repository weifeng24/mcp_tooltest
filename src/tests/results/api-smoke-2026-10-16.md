# L2 模型 API 冒烟记录（离线，mock 执行器）

日期：2026-10-16。性质：**模型决策链路验证**——模型 API 为真实调用（DeepSeek），工具执行为本地 mock（成功即返），不涉及车机。不能作为真机结论。

## 过程与发现

1. 首次冒烟失败：`provider_error`，HTTP 400 —— DeepSeek 要求函数名匹配 `^[a-zA-Z0-9_-]+$`，公司 MCP 工具名 `16777217.setTemp`（serviceId 前缀含点号）被 API 拒收。
2. 修复：模型适配层增加工具名双向映射（`ToolNameMapper`），API 侧用安全名、执行与证据用原始 MCP 名；补充 3 项单元测试。
3. 复跑通过。
