## 正式运行前冻结

记录每条任务的来源、确认人、完整工具名、Schema版本、参数语义、预期输出、时限和恢复方法。优先选择有真实标准答案的代表性工具。发现规范与实现差异时保留两者，不能以改预期消除失败。

`assertions` 按类型要求参数：field_equals须有path/value，tool_call_matches须有完整name/arguments，max_rounds须为正整数。`postconditions` 是执行器独立回读，模型不接触标准答案。

正向、边界、接口异常和模型不调用各自说明目的。框架的负面控制定义没有完整培训资料，验收分类需导师确认；任何负面用例都不能用基础设施错误冒充预期失败。

用例数按独立case_id计；重复次数和模型数不增加独立用例数。回放按现有事件队列消费，录制不足的条目保留在计划分母中。
