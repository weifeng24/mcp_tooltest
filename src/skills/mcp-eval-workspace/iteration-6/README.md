## 复核页面使用

在本机Ubuntu文件管理器中进入本目录，双击`review.html`用浏览器打开，无需登录或联网。页面的Outputs用于查看输入、实际回答和评分，Benchmark用于查看本轮对照；可填写意见并使用页面提供的提交/导出反馈功能。导出的`feedback.json`是用户反馈，尚未产生；如浏览器阻止本地文件加载，反馈可直接按场景编号写在对话中，不必重跑任务。

文件中的synthetic表示本地构造/合成场景。对真实缺陷、业务提效或实际部署的结论，需要对应真实证据。
